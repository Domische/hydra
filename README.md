# Hydra

Веб-приложение для визуального планирования. Пользователь создаёт доски, размещает на них визуальные элементы и добавляет компонент-ссылку на другую доску. Связанные доски образуют навигационную структуру, позволяющую переходить между рабочими областями.

Название отсылает к созвездию Гидра — самому большому и длинному созвездию неба. Цепочка связанных звёзд — как доски, связанные ссылками в навигационную структуру.

## Возможности

- Создание и удаление досок
- Размещение визуальных элементов (виджетов) на доске
- Компонент-ссылка на другую доску
- Переход между связанными досками
- Сохранение данных

## Как запустить

### Требования

- Node.js 20+
- Go 1.23+
- Git

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Приложение откроется на http://localhost:5173.

Backend

```bash
cd backend
go mod download
go run .
```

API будет доступно на http://localhost:8080.
