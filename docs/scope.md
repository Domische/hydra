# Scope — MVP

## Цель продукта

Предоставить простой инструмент для создания визуальных досок, размещения элементов и перехода между досками через компоненты-ссылки с сохранением данных.

## Что входит в MVP

- [ ] Создание/удаление досок
- [ ] Размещение визуальных элементов (виджетов) на доске
- [ ] Компонент-ссылка на другую доску
- [ ] Переход между связанными досками
- [ ] Сохранение данных

## Что НЕ входит в MVP

- Коллаборация в реальном времени
- Медиа-виджеты (видео, галереи)
- Каскадные обновления компонентов
- Офлайн-режим
- Граф связей (бэклог)
