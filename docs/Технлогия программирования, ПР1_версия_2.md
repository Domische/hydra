# 1. Назначение и область действия

Документ определяет требования к первой версии веб-приложения для
визуального планирования. Пользователь создаёт доски, размещает на них
визуальные элементы и добавляет компонент-ссылку на другую доску.
Связанные доски образуют навигационную структуру, позволяющую переходить
между рабочими областями.

## 1.1. Цель продукта

Предоставить простой инструмент для создания визуальных досок,
размещения элементов и перехода между досками через компоненты-ссылки с
сохранением данных.

## 1.2. Входит в первую версию

- Создание, просмотр, переименование и удаление досок.
- Добавление и редактирование базовых визуальных элементов.
- Добавление компонента, ссылающегося на выбранную доску.
- Переход к целевой доске по компоненту.
- Сохранение досок, элементов и связей между перезагрузками страницы.
- Обработка ситуации, когда целевая доска удалена или недоступна.

## 1.3. Не входит в первую версию

- Совместное редактирование в реальном времени.

- Сложная система ролей и прав доступа, чат, комментарии и история
  версий.

- Мобильное приложение и офлайн-режим.

# 3. Термины

| Термин         | Определение                                                                                            |
| ------------------ | ---------------------------------------------------------------------------------------------------------- |
| Доска              | Рабочая область, на которой пользователь размещает визуальные элементы.                                    |
| Визуальный элемент | Базовый объект на доске, например, текстовый блок или фигура; точный набор типов определяется реализацией. |
| Компонент-ссылка   | Элемент на исходной доске, который хранит ссылку на конкретную целевую доску и позволяет открыть её.       |
| Исходная доска     | Доска, на которой размещён компонент-ссылка.                                                               |
| Целевая доска      | Доска, на которую указывает компонент-ссылка.

# 7. Ограничения и допущения

- Проект выполняется командой из четырёх человек в рамках учебного
  задания и ограниченного срока.
- Рабочий процесс организован по Kanban; задачи видимы команде.
- В первой версии поддерживается согласованный базовый набор визуальных
  элементов.
- Совместное редактирование в реальном времени и сложные права доступа
  не входят в обязательный объём.
- Компонент-ссылка указывает на одну целевую доску.

# 9. Проверка непротиворечивости

- Каждому сценарию соответствует минимум одно требование.
- Переименование целевой доски не разрывает компонент: связь
  определяется устойчивым идентификатором, а не только названием.
- Удаление целевой доски не удаляет исходную доску и не приводит к
  аварии.
- Требование сохранения данных проверяется после обновления страницы.
- Критерии приёмки описывают наблюдаемые результаты, а не субъективные
  оценки.

# 12. Бизнес-контекст продукта

## 12.1. Миссия 

Миссия продукта - помочь людям и командам наглядно организовывать идеи и
рабочую информацию, связывая отдельные визуальные доски в единую
структуру. Ключевая ценность - возможность использовать целую доску как
компонент-ссылку и переходить между связанными рабочими пространствами,
не теряя контекст.

# 13. Целевая аудитория

Первичная целевая аудитория - студенты, преподаватели, дизайнеры,
проектные менеджеры и небольшие команды, которым нужно визуально
структурировать идеи, планы и материалы, распределённые по нескольким
доскам. Для первой версии основным сценарием считается индивидуальная
организация информации с переходами между связанными досками;
полноценная совместная работа команды может быть добавлена позднее.

| Сегмент | Задача / потребность |
|----|----|
| Студенты и учебные команды | Структурировать материалы проекта, этапы работы и взаимосвязанные темы. |
| Дизайнеры и UX/UI-специалисты | Связывать доски исследования, пользовательских сценариев, идей и решений. |
| Проектные менеджеры и небольшие команды | Разделять планирование по направлениям, сохраняя переходы между областями проекта. |
| Преподаватели | Организовывать учебные материалы и активности по отдельным связанным доскам. |

Портрет первичного пользователя: человек, который ведёт несколько досок
по одной теме и хочет связывать их напрямую, вместо того чтобы
копировать содержимое или вручную искать нужную доску.
